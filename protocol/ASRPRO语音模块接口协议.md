# ASRPRO 2.0 语音识别模块 · 接口协议文档

> **模块**: ASRPRO 2.0（基于 CI1302 芯片，启英泰伦第3代 BNPU）
> **用途**: 为桌上宠物提供离线语音识别能力
> **接入点**: ESP32-S3-BOX-3-DOCK 的 UART1（GPIO 待确认，见第七节备选方案）
> **状态**: 协议已定义，代码待实现（Phase 2+）

---

## 一、模块硬件规格

| 参数 | 值 |
|------|----|
| 核心芯片 | CI1302（启英泰伦第3代 BNPU V3.0）|
| 工作电压 | 3.6V – 5V |
| 工作电流 | 待机 ~500µA，识别峰值 ~150mA |
| SPI Flash | 2MB（ASRPRO-2M）或 4MB（ASRPRO-4M）|
| 板载麦克风 | 单麦，360° 拾音，支持降噪/回声消除 |
| 板载喇叭 | 支持直接驱动小喇叭（音频输出引脚）|
| 最大命令数 | 300 条 |
| 识别率 | >95%–98% |
| 识别距离 | 最远 10 米 |
| 默认波特率 | 9600 bps, 8N1 |
| 可用接口 | UART ×3, I²C, GPIO ×10, PWM ×6, SPI |

### 引脚说明（ASRPRO 2.0 开发板）

```
┌──────────────────────────────┐
│           ASRPRO 2.0         │
│                              │
│  [VCC] [GND] [TXD] [RXD]    │  ← 核心4线（电源+串口）
│  [PA0] [PA1] [PA2] [PA3]    │  ← 扩展 GPIO
│  [PA4] [PA5] [PA6] [PA7]    │  ← 扩展 GPIO

└──────────────────────────────┘
```

## 二、硬件接线方案

### 连接 ESP32-S3

```
ASRPRO 2.0                    ESP32-S3-BOX-3-DOCK
┌──────────┐                  ┌─────────────────────┐
│  TXD     │─────────────────►│  GPIO_RX (UART1)    │
│  RXD     │◄─────────────────│  GPIO_TX (UART1)    │
│  GND     │──────────────────│  GND                │
│  VCC     │───── 5V ────────│  5V (或独立供电)      │
└──────────┘                  └─────────────────────┘
```

> **TX-RX 交叉连接**: ASRPRO TX → ESP32 RX，ASRPRO RX ← ESP32 TX
> **注意**: GPIO43/44 已被 UART2(STC-B通信) 占用，ASRPRO 需使用其他 GPIO。

### ESP32 三个 UART 的分配

| UART | 引脚 | 用途 | 状态 |
|------|------|------|------|
| UART0 | USB 内置 | PC 调试串口 (115200) | 已分配 |
| UART2 | **GPIO43**(TX) **GPIO44**(RX) | STC-B 通信 (9600) | 已分配 |
| **UART1** | **待选 GPIO** (见备选方案) | **ASRPRO 语音 (9600)** | **待分配** |

> **BOX-3-DOCK 可用 Pmod GPIO**:
> - 左上: GPIO4, GPIO38, GPIO19, GPIO21
> - 右上: GPIO40, GPIO39, GPIO20, GPIO42
> - 左下: GPIO43⚠️, GPIO1, GPIO14, GPIO10
> - 右下: GPIO44⚠️, GPIO12, GPIO9, GPIO13
> - ⚠️ = 已被 UART2(STC-B) 占用
>
> **推荐 ASRPRO 引脚**: GPIO40(TX) + GPIO39(RX)（右上 Pmod，远离 STC-B 引脚）

### 供电注意

- ASRPRO 识别时峰值电流 ~150mA，ESP32-S3-BOX-3-DOCK 的 5V 引脚通常可提供 500mA
- 如果同时驱动喇叭输出，建议用外部 5V 电源独立供电 ASRPRO
- 确保 GND 共地

## 三、ASRPRO 串口通信协议

### 3.1 识别结果帧格式（ASRPRO → ESP32）

ASRPRO 识别到语音命令后，通过 UART 发送 **5字节固定帧**：

```
┌────────┬────────┬─────────┬────────┬────────┐
│ 帧头1   │ 帧头2   │ 命令ID   │ 帧尾1   │ 帧尾2   │
│ 0xAA   │ 0x55   │ 0xNN   │ 0x55   │ 0xAA   │
│ 1 Byte │ 1 Byte │ 1 Byte │ 1 Byte │ 1 Byte │
└────────┴────────┴─────────┴────────┴────────┘
```

| 字段 | 值 | 说明 |
|------|----|------|
| 帧头 | `0xAA 0x55` | 固定两字节起始标志 |
| 命令ID | `0xNN` | 当前识别到的语音命令编号（1字节，0x01–0xFF）|
| 帧尾 | `0x55 0xAA` | 固定两字节结束标志 |

**总帧长**: 固定 5 字节
**波特率**: 9600 bps, 8N1

### 3.2 命令ID分配规则

命令ID 是在 ASRPRO 配套软件中配置语音命令时指定的，每个命令对应一个唯一 ID。

**本项目建议的命令ID分配表**:

| ID (hex) | 语音命令（唤醒词后） | 分类 | 对应宠物行为 |
|----------|---------------------|------|-------------|
| `0x01` | "吃饭啦" / "开饭了" | 互动 | 喂食（= K1） |
| `0x02` | "一起玩" / "玩耍时间" | 互动 | 玩耍（= K2） |
| `0x03` | "摸摸头" / "乖" | 互动 | 摸头（= K3） |
| `0x04` | "站起来" / "跳个舞" | 动作 | 步进电机动作 |
| `0x05` | "唱首歌" / "来一首" | 娱乐 | 播放旋律 |
| `0x10` | "你好吗" / "心情怎样" | 查询 | 显示当前心情 |
| `0x11` | "几点了" / "现在时间" | 查询 | 数码管显示时间 |
| `0x12` | "你饿了吗" / "饱不饱" | 查询 | 根据饱食度回应 |
| `0x13` | "多大了" / "你几岁" | 查询 | 显示年龄/等级 |
| `0x20` | "晚安" / "睡觉吧" | 模式 | 进入睡眠模式 |
| `0x21` | "早上好" / "起床了" | 模式 | 起床动画 |
| `0x22` | "生气" / "哼" | 趣味 | 生气表情 |
| `0x23` | "开心" / "棒棒的" | 趣味 | 超开心表情 |

### 3.3 唤醒词

ASRPRO 支持设置**唤醒词**（类似 "Hey Siri"），说出唤醒词后模块进入聆听状态，等待后续命令。

**建议唤醒词**: "小宠物" / "小宠小宠"

> 唤醒词在 ASRPRO 配套软件中配置，不需要 ESP32 处理。
> 唤醒时 ASRPRO 也可以输出一个命令ID（如 `0x00`），ESP32 可据此让宠物显示"聆听"表情。

### 3.4 音频反馈

ASRPRO 板载喇叭输出，可以为每个命令配置语音回复：

| 命令ID | 语音回复内容 |
|--------|-------------|
| `0x01` | "好香呀，谢谢主人~" |
| `0x02` | "好开心，再玩一次吧！" |
| `0x03` | "呼噜噜~好舒服~" |
| `0x10` | "我心情还不错哦！" / "有点饿了..." |
| `0x20` | "晚安，做个好梦~" |
| `0x21` | "早上好！新的一天开始啦~" |

> 语音回复由 ASRPRO 内部处理，不经过 ESP32。
> 但 ESP32 同时收到命令ID后，会驱动 STC-B 做表情/LED/蜂鸣器联动。

## 四、ESP32 端解析逻辑（伪代码）

```
UART1 接收状态机:
  状态0: 等待 0xAA → 进入状态1
  状态1: 等待 0x55 → 进入状态2（否则回状态0）
  状态2: 读取命令ID → 保存
  状态3: 验证 0x55 → 进入状态4（否则回状态0）
  状态4: 验证 0xAA → 帧完整，分发命令ID（否则回状态0）
```

| `ESP32/src/VoiceModule.cpp` | 5字节帧状态机解析 + 命令分发 |

## 五、ASRPRO 配套软件配置

ASRPRO 需要使用官方配套软件来配置语音命令词和回复语。

### 配置流程

1. **下载配套软件**: 从卖家提供的链接或[启英泰伦官网](https://help.aimachip.com/)下载
2. **创建项目**: 选择芯片型号 CI1302，选择 Flash 大小（2M/4M）
3. **设置唤醒词**: 输入唤醒词文字（如 "小宠物"）
4. **添加命令词**: 逐条添加语音命令，指定对应的命令ID（hex）
5. **设置回复语**: 为每条命令配置 TTS 语音回复文字
6. **生成固件**: 软件自动生成固件文件
7. **烧录**: 通过 USB 转串口（CH340）烧录到 ASRPRO 模块

### 配置注意事项

- 命令词尽量使用**2-6个字**的短句，识别率更高
- 避免发音相近的命令词（如 "开灯" 和 "关灯" 容易混淆）
- 唤醒词建议 **3-4个字**，避免常见词语（防误唤醒）
- 每条命令的回复语限制约 **30个汉字**
- 可以设置**组合命令**：唤醒 → 命令 → 回复 一体化

## 六、语音 + 按键 + 传感器 联动逻辑

语音命令触发后，ESP32 的处理与按键触发**复用同一套状态机逻辑**：

```
                    ┌─────────────┐
  按键 K1/K2/K3 ──►│             │
                    │  PetState   │──► 表情/LED/音效 ──► STC-B 数码管
  语音命令 ID   ──►│  状态机      │
                    │             │──► 属性变化（饱食/精力/快乐/好感）
  导航/振动/霍尔──►│             │
                    └─────────────┘
```

| 语音命令 | 等效按键 | PetState 调用 |
|---------|---------|---------------|
| `0x01` 吃饭 | K1 | `onButtonPress(1)` |
| `0x02` 玩耍 | K2 | `onButtonPress(2)` |
| `0x03` 摸头 | K3 | `onButtonPress(3)` |
| `0x04` 跳舞 | — | `onVoiceDance()` (新增) |
| `0x05` 唱歌 | — | `onVoiceSing()` (新增) |
| `0x10` 心情 | — | `onVoiceQueryMood()` (新增) |
| `0x20` 晚安 | — | `onVoiceSleep()` (新增) |
| `0x21` 早安 | — | `onVoiceWake()` (新增) |

> 核心设计原则：**语音命令只是多了一种输入方式**，底层走同一套状态机。
> STC-B 端完全不需要改动。

## 七、待确认问题（实现前需确定）

| # | 问题 | 影响 |
|---|------|------|
| 1 | ASRPRO 模块的**具体型号**（2M 还是 4M）| 影响 Flash 容量，决定能存多少命令词和回复语 |
| 2 | 是否需要 ASRPRO **板载喇叭**播放语音回复 | 如果需要，喇叭接线方案（可固定在宠物外壳内）|
| 3 | 唤醒词的选择（"小宠物" / 自定义）| 在配套软件中配置 |
| 4 | 是否需要**二级命令**（唤醒后等待多个命令 vs 唤醒+命令一体）| 影响交互流程设计 |
| 5 | ASRPRO 的供电方案（ESP32 的 5V 引脚 vs 独立供电）| 影响硬件接线 |
| 6 | 是否有 ASRPRO 的**配套软件**已安装 | 需要用配套软件配置命令词并生成固件 |
| 7 | ASRPRO 的 UART1 GPIO 选择 | GPIO43/44 已被 UART2(STC-B) 占用，推荐用 GPIO40(TX)/39(RX) 右上 Pmod |
