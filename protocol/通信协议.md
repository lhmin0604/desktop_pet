# 桌上宠物 · STC-B ↔ ESP32-S3 通信协议 V1.0

## 一、硬件连接

```
STC-B (UART2 - EXT口)          ESP32-S3-BOX-3-DOCK
┌──────────────┐                ┌──────────────────┐
│  EXT TXD(5V) │──电平转换(3.3V)─►│  GPIO44 (RX2)   │
│  EXT RXD     │◄───────────────│  GPIO43 (TX2) 3.3V│
│  GND         │────────────────│  GND             │
└──────────────┘                └──────────────────┘

波特率: 9600 bps, 8N1
```

> **硬件**: ESP32-S3-BOX-3B + BOX-3-DOCK 扩展底座（Pmod 接口）
> **注意**: STC-B 的 EXT 口被 UART2 占用后，不能再使用 `EXTInit()`。
> **电平**: ESP32 TX(3.3V) → STC RX 可直连；STC TX(5V) → ESP32 RX **必须加电平转换**（电阻分压或逻辑电平转换芯片）。
> **备选引脚**: 如 GPIO43/44 与 USB 调试冲突，可改用 GPIO40/39 或 GPIO38/4。

## 二、帧格式

```
┌──────┬──────┬──────┬───────────┬──────┐
│ 帧头  │ 命令  │ 长度  │  数据载荷  │ 校验  │
│ 1 Byte│ 1 Byte│ 1 Byte│ 0~16 Bytes│ 1 Byte│
└──────┴──────┴──────┴───────────┴──────┘
```

| 字段 | 偏移 | 长度 | 说明 |
|------|------|------|------|
| HEAD | 0 | 1 | 固定 `0xAA` |
| CMD  | 1 | 1 | 命令码 |
| LEN  | 2 | 1 | 数据载荷长度（0~16）|
| DATA | 3 | LEN | 数据内容 |
| CHK  | 3+LEN | 1 | 校验 = `HEAD ^ CMD ^ LEN ^ DATA[0] ^ ... ^ DATA[n]` |

**最大帧长**: 4 + 16 = 20 字节

## 三、命令定义

### 3.1 ESP32 → STC-B（下行指令）

| CMD | 名称 | DATA 格式 | 说明 |
|-----|------|----------|------|
| `0x01` | SET_EXPRESSION | `[expr_id]` (1字节) | 设置宠物表情 |
| `0x02` | SET_CUSTOM_FACE | `[s0..s7]` (8字节) | 自定义段码表情 |
| `0x03` | SET_LED | `[led_byte]` (1字节) | 设置8个LED状态 |
| `0x04` | SET_BUZZER | `[freq_H, freq_L, time_H, time_L]` (4字节) | 蜂鸣器，频率Hz+时长(×10ms) |
| `0x05` | SET_MOTOR | `[speed, steps_H, steps_L]` (3字节) | 步进电机，速度+步数(有符号) |
| `0x06` | PLAY_SOUND | `[sound_id]` (1字节) | 播放预定义音效 |
| `0x07` | SET_ALL | `[expr, led, sound]` (3字节) | 一次设置表情+LED+音效 |
| `0x10` | QUERY_SENSOR | 无数据 | 请求传感器数据 |
| `0x11` | QUERY_TIME | 无数据 | 请求当前时间 |
| `0xF0` | SYS_PING | 无数据 | 心跳/检测在线 |
| `0xF1` | SYS_RESET | 无数据 | 宠物状态重置 |

### 3.2 STC-B → ESP32（上行数据）

| CMD | 名称 | DATA 格式 | 说明 |
|-----|------|----------|------|
| `0x20` | SENSOR_REPORT | `[tH,tL, lH,lL, keys, flags]` (6字节) | 传感器数据上报 |
| `0x21` | TIME_REPORT | `[Y,M,D,W,h,m,s]` (7字节,BCD) | 时间数据上报 |
| `0x22` | EVENT_REPORT | `[event_type, event_data]` (2字节) | 硬件事件上报 |
| `0xE0` | ACK_OK | `[原CMD]` (1字节) | 命令确认成功 |
| `0xE1` | ACK_FAIL | `[原CMD, error]` (2字节) | 命令确认失败 |
| `0xF0` | SYS_PONG | 无数据 | 心跳回应 |

### 3.3 SENSOR_REPORT 字段详解

```
Byte0: temperature_H    ┐
Byte1: temperature_L    ┘ ADC值 (0-1023), 来自 NTC 热敏电阻
Byte2: light_H          ┐
Byte3: light_L          ┘ ADC值 (0-1023), 来自光敏电阻
Byte4: buttons          按键状态 bit[2:0] = K3,K2,K1 (1=按下)
Byte5: flags            bit0=振动触发, bit1=霍尔触发
```

### 3.4 EVENT_REPORT 事件类型

| event_type | 说明 | event_data |
|------------|------|-----------|
| `0x01` | 按键事件 | 按键ID(1-3) |
| `0x02` | 导航按键 | 方向(右=1,下=2,中=3,左=4,上=5) |
| `0x03` | 振动检测 | 0x01 |
| `0x04` | 霍尔检测 | 0x01=靠近, 0x00=离开 |

## 六、交互时序

### 6.1 正常命令交互

```
ESP32                          STC-B
  │                               │
  │──── SET_EXPRESSION(笑脸) ────►│
  │                               │ (执行表情切换)
  │◄──── ACK_OK(0x01) ───────────│
  │                               │
```

### 6.2 传感器查询

```
ESP32                          STC-B
  │                               │
  │──── QUERY_SENSOR ────────────►│
  │                               │ (采集ADC数据)
  │◄──── SENSOR_REPORT ──────────│
  │                               │
```

### 6.3 事件上报（STC-B 主动发送）

```
ESP32                          STC-B
  │                               │
  │                               │ (用户按下K1)
  │◄──── EVENT_REPORT(按键) ─────│
  │                               │
```

### 6.4 心跳检测

```
ESP32                          STC-B
  │                               │
  │──── SYS_PING ────────────────►│
  │                               │
  │◄──── SYS_PONG ───────────────│
  │                               │
```

## 七、注意事项

1. **帧间隔**：两帧之间至少间隔 **10ms**，避免接收端缓冲区溢出
2. **超时重传**：ESP32 发送命令后 **500ms** 未收到 ACK，可重传（最多3次）
3. **STC-B 响应延迟**：所有命令必须在 **5ms** 内回复 ACK（BSP 1ms 节拍保证）
4. **传感器定时上报**：STC-B 每 **500ms** 主动上报一次传感器数据（无需 ESP32 请求）
5. **事件立即上报**：按键/振动/霍尔事件发生后立即上报，不等轮询
6. **校验错误**：接收端校验失败时静默丢弃该帧，不回复（发送端靠超时重传）
7. **波特率**：双方必须同为 **9600 bps**（可在初始化时调整）
