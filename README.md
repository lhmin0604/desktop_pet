# 🐾 桌上宠物 Desktop Pet

> STC-B 学习板 × ESP32-S3-BOX-3B 协作桌上宠物

## 项目概述

用 STC-B 学习板做宠物的"身体"（显示、传感器、交互），
用 ESP32-S3 做宠物的"大脑"（状态逻辑、联网、智能行为）。

## 硬件需求

| 硬件 | 型号 | 角色 |
|------|------|------|
| 开发板1 | STC-B 学习板 (STC15F2K60S2) | 身体：数码管表情、LED、蜂鸣器、传感器、按键 |
| 开发板2 | ESP32-S3-BOX-3B + BOX-3-DOCK | 大脑：宠物状态机、WiFi联网、行为决策 |
| 电平转换 | 电阻分压或电平转换芯片 | STC TX(5V) → ESP32 RX(3.3V) |
| 连接线 | 杜邦线 ×3 + 电平转换 | TX-RX 交叉连接 + GND |

## 接线方法

```
STC-B (EXT 扩展口)           ESP32-S3-BOX-3-DOCK
┌─────────────┐              ┌─────────────────────┐
│  EXT TXD(5V)│──电平转换───►│  GPIO44 (RX2)        │
│  EXT RXD    │◄─────────────│  GPIO43 (TX2) 3.3V   │
│  GND        │──────────────│  GND                 │
└─────────────┘              └─────────────────────┘
```

> ⚠️ **TX-RX 交叉连接**：STC-B 的 TX 接 ESP32 的 RX，反之亦然。
> ⚠️ **共地**：两块板子的 GND 必须连在一起。
> ⚠️ **电平转换（必须）**：ESP32 TX(3.3V) → STC RX 可直连；但 STC TX(5V) → ESP32 RX(3.3V) **必须加电平转换**！推荐用电阻分压（2KΩ+3.3KΩ）或双向逻辑电平转换模块。直连会**损坏 ESP32-S3**。
> ⚠️ **GPIO43/44** 在 BOX-3-DOCK 左下/右下 Pmod 接口上（标注 U0TXD/U0RXD，但通过 GPIO Matrix 映射为 UART2）。

## 快速开始

### STC-B 端
1. 打开 Keil C51，创建新工程
2. 选择芯片 `STC15F2K60S2`
3. 将 `STC-B/inc/` 和 `STC-B/source/` 中的文件加入工程
4. 同时将 BSP 库文件 (`sys.H`, `displayer.H`, `Beep.h`, `Key.H`, `adc.h`, `uart2.h`, `Vib.h`, `hall.H`, `DS1302.h` 及对应 `.lib`) 加入工程
5. 编译，用 STC-ISP 烧录到 STC-B 板

### ESP32-S3 端
1. 安装 Arduino IDE + ESP32 开发板支持包
2. 选择开发板 `ESP32S3 Dev Module`
3. 打开 `ESP32/src/desktop_pet/desktop_pet.ino`
4. 所有 `.cpp` / `.h`（PetDisplay / PetState / PetProtocol）已在 `desktop_pet/` 同目录下，无需额外配置路径
5. 编译上传到 ESP32-S3-BOX-3B

### 联调
1. 按接线图连接两块板子
2. 打开 ESP32 的串口监视器 (115200)
3. 应看到：`[系统] 初始化完成，等待 STC-B 连接...`
4. STC-B 上电后，ESP32 应收到心跳回应：`[心跳] STC-B 在线`
5. 按 STC-B 上的 K1/K2/K3 测试交互

## 交互方式

| 操作 | 效果 |
|------|------|
| 按 K1 | 🍖 喂食，饱食度+20 |
| 按 K2 | 🎮 玩耍，快乐+15 |
| 按 K3 | 🤚 摸头，好感度+10 |
| 拍桌子 | 📳 振动传感器触发 |
| 磁铁靠近 | 🧲 霍尔传感器 = 摸摸 |
| 导航↑ | 惊喜表情 |
| 导航● | 开心 + 全LED亮 |
| 环境变暗 | 🌙 宠物想睡觉 |
| 环境变冷/热 | 😤 宠物不高兴 |

## 宠物属性系统

| 属性 | 范围 | 说明 |
|------|------|------|
| 饱食度 | 0-100 | 每分钟自然-1，喂食+20 |
| 精力值 | 0-100 | 每2分钟自然-1，玩耍消耗-5 |
| 快乐值 | 0-100 | 每90秒自然-1，互动增加 |
| 好感度 | 0-100 | 摸头+10，不互动不衰减 |
| 等级 | 1-10 | 每10分钟自动升一级 |
